MyFirstARProject

This project was developed in Unity using the Vuforia Engine to demonstrate interaction between two different 3D dragon models placed on separate images through Image Trackers.

Description

Each tracked image (Image Target) displays a distinct dragon.
Both dragons start in the Idle animation state.
When the distance between the two dragons becomes small enough, both transition into the Attack animation state.

Technologies Used
Unity (game engine and scripting)
Vuforia Engine 11.4.4
C# scripts for distance detection and animation control
